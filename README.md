# aggBias

An R package for selecting industry groups with low
input-output aggregation bias.

## Installation

Install the development version from GitHub:

```r
install.packages("remotes")
remotes::install_github("YOUR_USERNAME/aggBias")
```

Load the package:

```r
library(aggBias)
```

## Overview

aggBias provides tools for evaluating input-output
aggregation bias and selecting industry groupings
that reduce information loss during aggregation.
